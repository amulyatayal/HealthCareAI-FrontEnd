# Hero Background Image

## Adding Your Hero Background Image

To add a background image to the hero section (similar to Giga.ai), place your image file in this directory (`/public/`) with the filename:

**`hero-background.jpg`**

## Recommended Specifications

- **Format**: JPG, WebP, or PNG
- **Dimensions**: 1920x1080 or larger (will be cropped/centered automatically)
- **File size**: Optimized for web (< 500KB recommended)
- **Content**: Healthcare/AI themed image that works well with dark overlay

## How It Works

The image will be displayed with:
- 30% opacity
- Dark gradient overlay for text readability
- Responsive scaling on all devices
- Fallback gradient if image doesn't load

## Image Sources

You can find suitable healthcare/AI themed images from:
- **Unsplash**: https://unsplash.com/s/photos/healthcare-technology
- **Pexels**: https://www.pexels.com/search/medical-technology/
- **Pixabay**: https://pixabay.com/images/search/medical%20technology/
- Or use your own branded imagery
